本程式使用 Linked List 來儲存每個出現過的字元以及其出現次數。當讀入一個新的字元時，程式會先在 Linked List 中進行搜尋，如果找到相同的字元，則將該節點的 count 加一，如果沒有找到，則建立一個新的節點並加入 Linked List

搜尋方式使用逐次找法，也就是從 head 開始逐一比對節點，因此每次搜尋的時間複雜度為 O(n)

時間複雜度分析如下：
最好情況：O(n)
平均情況：O(n)
最壞情況：O(n²)

最壞情況發生在所有字元都不同時，每次搜尋都需要遍歷整個 Linked List

加分題解說：(檔案 "/加分題/main.c")

如果要降低搜尋時間，可使用 Hash Table，由於字元有固定的 ASCII 編碼（0~255），可以建立一個大小為 256 的陣列來記錄每個字元出現的次數
當讀入字元時，直接利用 ASCII 值作為陣列索引並增加計數即可，不需要進行搜尋

此方法每次操作時間為 O(1)，整體只需處理 n 個字元，因此整體時間複雜度為 O(n)，相比 Linked List，Hash Table 可以更有效的降低搜尋時間並提升效率
